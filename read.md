# Prompt Tuner Chatbot 🎯

An interactive chatbot to experiment with **prompt engineering**:
- Define roles, goals, and few-shot examples.
- Observe how responses change with different prompt styles.
- Built with Python, Streamlit, and OpenAI API.

## Features
- Role-based prompting
- Few-shot examples
- Adjustable creativity (temperature)
- Simple UI with Streamlit
